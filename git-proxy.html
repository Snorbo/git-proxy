Snorbo's GitHub 加速代理

这是一个基于 Cloudflare Workers 构建的 GitHub 代理加速服务，旨在解决部分网络环境下 GitHub 资源下载缓慢、克隆失败等问题。

支持 Release、Raw、Gist 以及仓库主页链接

🛠️ 使用方法

在任意需要加速的 GitHub 链接前，直接加上代理前缀：https://git-proxy.snorbo.vip/

1. Git Clone 仓库加速

git clone https://git-proxy.snorbo.vip/https://github.com/torvalds/linux.git

2. Release 附件下载

wget https://git-proxy.snorbo.vip/https://github.com/Fndroid/clash_for_windows_pkg/releases/download/0.20.25/Clash.for.Windows.Setup.0.20.25.exe

3. Raw 文件获取 (安装脚本)

curl -O https://git-proxy.snorbo.vip/https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh

⚠️ 注意事项

  • 本服务由个人 (Snorbo) 搭建与维护，资源有限，请勿使用脚本进行大批量或超大文件的恶意下载。
  • 代理服务可能会隐藏您真实的 IP 地址，如果在克隆私有仓库时遇到鉴权问题，建议使用 SSH 方式或官方原生链接。
  • 本代理不会存储您的任何个人信息或源码数据，所有请求均通过 Cloudflare 网络直接转发。
